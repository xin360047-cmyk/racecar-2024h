瞄准算法：云台PID + 坐标转换

最难的部分——小车在动，靶面固定的，要让激光始终打在靶心或画圆
云台控制基础
/* 舵机控制——PWM 50Hz，脉宽 0.5ms~2.5ms 对应 0°~180° */ void mod_gimbal_set(uint8_t h_angle, uint8_t v_angle) { // h_angle: 0~180，水平舵机角度 // v_angle: 0~180，俯仰舵机角度 // 内部换算：angle → PWM脉宽 // pulse = 500 + (angle / 180) * 2000 (单位 μs) // 50Hz PWM = 周期 20000μs，占空比 pulse/20000 uint16_t pulse_h = 500 + h_angle * 2000 / 180; uint16_t pulse_v = 500 + v_angle * 2000 / 180; bsp_pwm_set(CH_SERVO_H, pulse_h); // 水平舵机 bsp_pwm_set(CH_SERVO_V, pulse_v); // 俯仰舵机 } /* ⚠ 实际舵机 0°~180°可能不精确对应0.5~2.5ms，需要实测校准 * 装好云台后，写个测试程序在不同角度下标记位置对比 */
静态瞄准流程（基本要求）
1
云台回中位
h_angle=90, v_angle=90。上电后先归零
2
粗略扫描靶面
云台水平从0°→180°慢扫，激光不射（或者极短脉冲），观察靶纸上光斑最亮的区域在哪里
3
精确瞄准靶心
锁定到靶心区域后，用云台PID微调，射激光确认光斑位置
4
射击
激光连续照射，打靶记录
跑动中瞄准（发挥部分关键）

小车在AB段出发，沿正方形逆时针行驶。激光要始终瞄准靶心。

关键思路：靶面相对赛道的位置固定（AB边外50cm）。小车在不同位置时，激光指向靶面的角度不同。

/* 坐标转换：根据小车在赛道上的位置，算出云台应指的角度 */ void coord_update(uint8_t segment, float pos_in_segment) { // segment: 小车当前在哪条边上（0=A→B, 1=B→C, 2=C→D, 3=D→A） // pos_in_segment: 在边上的位置百分比 0~1.0 // // 靶心相对于小车的方向 = f(segment, pos_in_segment) // 这个函数需要你实际测量几个点，然后插值算出任意位置的角度 if (segment == 0) { // A→B：在AB边上横向移动 mod_gimbal_set(∠水平, ∠俯仰); // 这两个值需要实测标定 } } /* ⚠ 我没办法告诉你具体数值——不同小车的云台安装高度、激光到云台的距离、靶位距离都不一样 * 必须自己做一次标定：车放4个顶点+边中点，手动调云台找到靶心，记录角度值，再编程插值 */
画圆算法（发挥部分3）

要求：小车跑1圈，激光在靶面上同步画1圈半径6cm的圆。

思路：靶面上半径6cm的圆 → 换算成云台角度的变化范围。小车跑全程（4条边），云台同步做一个完整的圆运动。

但我不确定这个换算公式该怎么算——靶面是垂直的，云台需要把水平角度和俯仰角度联动起来才能画圆，这涉及三角函数。我没有实际验证过，不能乱教。这个部分建议你查一下二维云台画圆的资料，或者实测标定几个点再拟合。

这个页面的内容我不确定的地方

  • 画圆时水平舵机和俯仰舵机的相位关系——我不确定应该用正弦还是余弦组合
  • 上面这些内容是我根据原理推的，不是实测过的，不能保证准确性。拿到硬件后自己做标定会靠谱很多
